# Mission 1: Welcome to the Cloud

## Mission Overview

This laboratory activity introduces the basic Linux environment, cloud-based playgrounds, technical documentation, and GitHub version control used by cloud professionals.

## Objectives

- Access a cloud-based Linux environment using KillerCoda.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a GitHub repository.
- Document technical work using Markdown.

## Activities Performed

- Accessed the Ubuntu Linux environment using KillerCoda.
- Created a new Linux user account.
- Logged in using the newly created account.
- Gathered Linux system information.
- Created directories and Markdown files.
- Created a public GitHub repository.
- Organized laboratory documentation.
